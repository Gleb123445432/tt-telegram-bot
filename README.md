# TikTok Telegram Bot — Render Free

Обновлённая версия для Render Free.

## Что исправлено
- yt-dlp зафиксирован на 2026.08.19 — эта версия содержит исправления TikTok extractor/challenge.
- Добавлены retries для загрузки.
- Сохраняется работа через Telegram webhook.
- `RENDER_EXTERNAL_URL` и `PORT` берутся из переменных Render автоматически.

## Переменные Render
- BOT_TOKEN — токен от @BotFather
- MAX_FILE_SIZE_MB — 49
